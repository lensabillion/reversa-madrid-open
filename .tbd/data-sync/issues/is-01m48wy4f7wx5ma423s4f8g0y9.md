Part 8 · Publish (the view API). GET /api/v1/lineage and GET /api/v1/lineage/{slug} read a lineage.json on every request and send no caching headers, so a public host and every browser re-download a 1.3 MB view (the AI Act's) that changes only when 'make lineage' rewrites it atomically. Add Cache-Control: public, max-age=<INFLUENCE_VIEW_MAX_AGE, default 3600, validated at app start>, a strong ETag from the view file's size and mtime in nanoseconds (for the list, from every view's (slug, size, mtime)), Last-Modified from the mtime (the list: the newest), and a 304 Not Modified with the same validators for a matching If-None-Match (RFC 9110 weak comparison, comma lists and '*'). HTTP semantics live in the router and a helper beside it; services/lineage_views.py only exposes the file stats, so FastAPI routes stay thin adapters over pure file readers. 404 and 500 keep their messages and carry Cache-Control: no-store. The frontend keeps cache: no-store until a follow-up bead switches it.
