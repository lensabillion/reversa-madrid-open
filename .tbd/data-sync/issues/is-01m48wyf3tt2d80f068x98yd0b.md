Part 8 · Publish (the explorer). frontend/lib/api-client.ts (readJson, line 44) and frontend/lib/use-resource.ts (readEvidence, line 16) call fetch(url, { cache: 'no-store' }), which tells the browser to bypass its HTTP cache entirely, so the Cache-Control, ETag and Last-Modified headers that rev-bxcj adds to GET /api/v1/lineage and GET /api/v1/lineage/{slug} never save a download. Switch those fetches to the default cache mode (omit the option, or 'default'): the browser then serves a fresh copy from its cache within max-age and revalidates with If-None-Match after it, receiving a 304 instead of 1.3 MB. PR #91 (lib/atlas-api.ts renamed to lib/api-client.ts) is merged on main, so this edits lib/api-client.ts directly. Keep the AbortSignal handling; update the Vitest tests that assert the fetch options; run make check-frontend; verify in a browser's network panel that a reload after 'make lineage' shows a 200 and a plain reload a 304 or a cache hit.
